## Issue list

1. **P0-001 — Major — `.build/phase-0/evidence/skills-before.txt` + `skills-after.txt`.** The two snapshots are byte-identical (same `md5 553c82f4…`) and were written 2 ms apart (`mtime 18:25:10.253` vs `.255`). They were captured in the same instant, so they do not actually bracket a before/after install. The empty `skills-diff.txt` therefore cannot demonstrate that the skill copy "did not overwrite any existing skill" — it only shows the current tree equals itself. The underlying no-overwrite claim is plausible (`--update=none` is non-destructive), but the exit criterion explicitly requires a genuine *before-and-after* diff and that evidence is not genuine. *Expected:* a `skills-before.txt` captured prior to the skill copy and a `skills-after.txt` captured after it, with the diff proving no pre-existing path changed; or, if the install predates this loop, a clear statement that no copy ran in this pass plus an integrity check (e.g. mtimes/hashes unchanged) rather than two same-instant snapshots.

2. **P0-002 — Minor — `web/src/data.js` (lines 26, 34, 37).** The earlier Vite prototype still contains claims that exceed `docs/CAPABILITIES.md` and the honesty contract: "Tax invoices, e-invoices and e-way bills are generated from the order" (CAPABILITIES: e-invoice is from Sales Invoice, e-way bill from delivery/invoice/stock docs — not the order), "On a secure cloud we host for you, with automatic backups" (NOT_SUPPORTED lists automatic backups as not-in-code), and an unsupported figure "₹59,000". These are already documented as not-to-ship in `TODO_FROM_OWNER.md` and Phase 0 deliberately did not edit `web/`, so this is carried risk rather than a shipped falsehood. *Expected:* the non-compliant prototype copy is scrubbed or quarantined before any page built on it ships (Phase 4 gate), and no invented rupee figure remains in the repo's live source.

3. **P0-003 — Minor — `.build/phase-0/evidence/skills-diff-note.txt`.** This file exists in the evidence dir but is not listed among the PLAN's deliverables (PLAN lists `repos.txt`, `skills-before.txt`, `skills-after.txt`, `skills-diff.txt` only). Deliverable list and on-disk artifacts are inconsistent. *Expected:* PLAN deliverable list and the evidence directory match exactly.

4. **P0-004 — Minor — `docs/TODO_FROM_OWNER.md` app accounting.** The bench app `wiki` is present under `~/Desktop/frappe-bench/apps` but appears nowhere in the TODO (neither in the off-limits client-app list nor acknowledged as a reviewed generic app). It is in fact the standard `frappe/wiki` app, so excluding it from the client list is correct, but the TODO gives no record that it was reviewed and deemed generic, leaving the "apps found" accounting incomplete. *Expected:* every app on the bench is accounted for — either listed as client-specific/off-limits or explicitly noted as a reviewed generic app.
