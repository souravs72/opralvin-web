# ADR 0007 — DPDP Act 2023 on the lead path

Date: 2026-10-25
Status: accepted

## Context

Leads are personal data of Indian residents. The Digital Personal Data Protection Act, 2023 (Act 22 of 2023) exists. Commencement is by notification under section 1(2). This ADR does not claim the Act is fully in force.

## Decision

The form has an explicit, purpose-bound consent checkbox. A privacy notice names the purpose: contacting the person about a process audit. Consent is stored with the lead. A deletion-request path is documented. A cookie banner is used only if a non-essential cookie is set. Prefer analytics that can run without one.

## Consequences

The privacy page is a Phase 4 page. The lead contract in `opralvin_site` refuses a payload with consent false.
